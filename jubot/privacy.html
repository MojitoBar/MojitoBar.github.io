주봇(Jubot) 개인정보처리방침

시행일: 2026-10-31

  • 주봇(Jubot)은 운영자 본인만 사용하는 개인 비서 앱입니다.
  • Google 계정 데이터(Gmail·캘린더)는 본인 기기에서만 읽기 용도로 처리합니다. 제3자에게 판매·공유·전송하지 않으며, 광고에 사용하지 않습니다.
  • Google API Services User Data Policy(Limited Use 요건 포함)를 준수합니다.
  • 보관과 삭제: 토큰은 본인 기기의 키체인에 보관합니다. Google 계정 설정에서 언제든 접근을 철회할 수 있습니다.
  • 문의: GitHub 프로필 (MojitoBar)

Jubot Privacy Policy

Effective date: 2026-10-31

  • Jubot is a personal assistant app used only by its operator.
  • Google account data (Gmail and Calendar) is processed read-only on the operator's own device. It is never sold, shared with, or transferred to third parties, and is not used for advertising.
  • Jubot complies with the Google API Services User Data Policy, including the Limited Use requirements.
  • Storage and deletion: tokens are stored in the keychain on the operator's own device. Access can be revoked at any time in the Google Account settings.
